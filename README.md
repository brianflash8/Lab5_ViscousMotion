# Лабораторна робота №5. Рух тіла у в'язкому середовищі (варіант 13)

Модель руху тіла під дією початкової швидкості з опором середовища F = −k·v. SFML 3 + CMake + vcpkg (маніфест `vcpkg.json`).

## Структура
- `physics/` – фізична модель (`ViscousBody`, аналітичний розв'язок), без залежності від SFML;
- `app/main.cpp` – графічна програма (введення / фізика / відображення розділені);
- `app/experiment.cpp` – консольний обчислювальний експеримент;
- `tests/` – модульні тести (14 тестів).

## Збірка (Windows, MSVC, Ninja)
```
set VCPKG_ROOT=<шлях до vcpkg>
cmake --preset default
cmake --build build
```
Перше налаштування завантажує і збирає SFML через vcpkg (кілька хвилин).

## Керування
Пробіл – пуск/пауза, R – перезапуск, ↑/↓ або колесо миші – коефіцієнт опору k, W/S – маса, ←/→ – початкова швидкість (діє після R),
I – імпульс, M – метод (РК4/Ейлер), `[` `]` – крок dt.
Аргументи командного рядка: `--k`, `--m`, `--v0`, `--dt`, `--method euler|rk4`, `--advance <с>`.

## Тести та експеримент
`build\lab5_tests.exe`, `build\experiment.exe`.
